unsigned long long hour,
unsigned long long minute,
unsigned long long second )

Creates a datetime using a specific year, month, day, hour, minute, and second.

Note
If this function fails, the returned datetime object will have all fields set to 0.
The 'hours' argument should be in 24-hour format. And the 'day' argument should be the day of the month (range of 1 to 31).
This function uses mktime(...) which does not support years before 1970.

◆ timey_query_day_name()

TIMEY_API void timey_query_day_name ( char * buffer,
size_t buffer_size,
unsigned char day_num,
bool is_wday,
bool use_abbreviated_name )

Obtains the corresponding day name and inserts it into a string buffer.

Note
The longest possible day name is 9 characters, so the buffer should have a size of at least 10 to account for the null terminator.
This function assumes the current day, month, and year should be used. For past or future dates, refer to the timestamp and datetime functions.
Parameters
bufferWhere the resulting day name should be placed.
buffer_sizeThe size of the buffer given.
day_numThe number of the day. This should range from 1 to 7, or 1 to 31 depending on the 'is_wday' argument.
is_wdayWhether or not 'day_num' should be interpreted as a weekday value or a month value. If this is true, then 'day_num' should range from 1 to 7 where 1 represents Sunday, and 7 represents Saturday. If this is false, then 'day_num' should range from 1 to 31, where 1 is the first day of the month, and 31 is the last possible day a month can have.
use_abbreviated_nameWhether or not the day's name should be abbreviated.

◆ timey_update_stopwatch()

TIMEY_API void timey_update_stopwatch ( timey_stopwatch * ts,
long double delta_time )

Updates a stopwatch.

Use this function in the program's main loop using the delta time value to update the stopwatch's time.

Note
If the stopwatch is using a target end time, this function automatically checks to see if the end time has been reached, and if it has, the stopwatch is paused, and the 'end_time_reached' field on the stopwatch will be true.
